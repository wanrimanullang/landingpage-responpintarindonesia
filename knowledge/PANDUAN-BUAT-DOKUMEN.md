## 🚀 Langkah-langkah Membuat Dokumen

### Step 1: Buat Dokumen Baru

**Google Docs:**
1. Buka https://docs.google.com
2. Klik "+ Blank" atau "Dokumen Kosong"

**Microsoft Word:**
1. Buka Microsoft Word
2. File → New → Blank Document

---

### Step 2: Copy Konten

1. Buka file **`KONTEN-SOP-UNTUK-DOCS.txt`** yang sudah saya buat
2. Copy SEMUA isinya (Ctrl+A lalu Ctrl+C)
3. Paste ke Google Docs/Word (Ctrl+V)

---

### Step 3: Insert Gambar di Setiap Langkah

Cari teks **[>>> INSERT GAMBAR xxx.png DI SINI <<<]** lalu ganti dengan gambar yang sesuai:

**Cara Insert Gambar di Google Docs:**
1. Klik tempat dimana ada teks `[>>> INSERT GAMBAR <<<]`
2. Hapus teks tersebut
3. Klik menu **Insert → Image → Upload from computer**
4. Pilih gambar yang sesuai
5. Resize gambar agar sesuai (klik gambar → drag corner)

**Cara Insert Gambar di Microsoft Word:**
1. Klik tempat dimana ada teks `[>>> INSERT GAMBAR <<<]`
2. Hapus teks tersebut
3. Klik menu **Insert → Pictures → This Device**
4. Pilih gambar yang sesuai
5. Resize gambar agar sesuai

---

### Step 4: Format Dokumen

**Judul Utama:**
- Select teks "BUKU PANDUAN SETUP CLIENT BARU"
- Ubah ke Heading 1 / Title
- Center alignment
- Bold

**Sub-judul (LANGKAH 1, LANGKAH 2, dst):**
- Select teks seperti "LANGKAH 1: AKSES MENU AUTOMATION BUILDER"
- Ubah ke Heading 2
- Bold

**Tabel:**
- Jika tabel tidak terformat dengan baik, buat ulang menggunakan Insert → Table

---

### Step 5: Export ke PDF

**Google Docs:**
1. File → Download → PDF Document (.pdf)

**Microsoft Word:**
1. File → Save As → Pilih PDF
